# 语迹 LangoTrace 多端 HTML 原型

这是语迹 / LangoTrace 的多文件静态 HTML 原型，用于进一步区分 iPhone、iPad、MacBook 三端体验。

## 打开方式

直接打开总览页：

```text
prototypes/langotrace-multi-device-prototype/index.html
```

也可以直接打开任意页面。该原型不需要启动本地服务器，不依赖 npm、框架、CDN、远程图片或远程字体。

当前示例主线使用中文 → 英语学习。首次启动先询问并记录用户的母语、目标语言和水平自评，用户确认后创建“英语空间”。用户之后可以添加“日语空间”“法语空间”等新的语言空间，但不把多种目标语言混在同一个空间。

## 文件结构

总览：

- `index.html`：三端页面入口和设计原则说明。
- `onboarding.html`：首次启动流程，先询问母语、目标语言和水平自评，确认后创建“英语空间”，不要求用户选择目录。

iPhone 页面：

- `iphone-today.html`：今日入口、快速记录、拍照和继续练习。
- `iphone-entry.html`：母语记录、AI 转换和生成模式。
- `iphone-practice.html`：听写、回译、跟读和复述。
- `iphone-memory.html`：词句、整句、相似记忆和复习。
- `iphone-settings.html`：AI Provider、同步、隐私、买断制授权和默认语言空间。

iPad 页面：

- `ipad-desk.html`：三栏沉浸学习桌面。
- `ipad-photo-ocr.html`：照片引导写作与手写 OCR 录入。
- `ipad-correction.html`：目标语言写作检测、修改和错误模式提取。
- `ipad-memory.html`：长期记忆地图、主题召回和成长轨迹。

MacBook 页面：

- `mac-library.html`：语言资料库、搜索、批量整理和预览。
- `mac-prompts.html`：Prompt Preset 管理。
- `mac-sync.html`：AI Provider、隐私、对象存储同步和本地向量索引。
- `mac-import-export.html`：导入导出、词典资源、备份和数据边界。

共享资源：

- `styles.css`：三端共享的视觉系统和布局样式。

## 三端定位

iPhone：

- 高频随手记录。
- 拍照生成写作话题。
- 短句听写、回译、跟读。
- 复习词句和相似记忆。
- 底部导航为“今日 / 记录 / 练习 / 记忆 / 设置”，不使用“我的”。

iPad：

- 主力学习桌面。
- 双语对照与逐句学习。
- 手写文章拍照录入与 OCR 校对。
- 目标语言写作检测与修改。
- 长期记忆地图。

MacBook：

- 语言资料库与创作工作台。
- 批量导入导出。
- Prompt Preset 管理。
- AI Provider 和对象存储高级配置。
- 数据备份、同步冲突和本地索引维护。

## 设计原则

- 高级、现代、克制。
- 更像 Apple 原生精品工具，而不是游戏化课程 App。
- 用生活记录作为界面主角。
- 隐私、本地优先和自定义配置必须被看见，但不能压过学习主流程。
- 三端共享同一套数据和学习逻辑，但界面结构按设备重做。
- 第一版首次通过问答引导创建一个目标语种空间，例如“英语空间”；之后可添加其他语言空间。首次启动不要求选择目录；目录迁移、备份和对象存储同步放在设置或 Mac 高级工作台。
- iPad 和 MacBook 使用轻量顶部全局条展示当前语言空间、保存/同步状态和设置图标；语言空间常驻但不做重型 Tab，设置可达但不抢主流程。
- 工作、生活、旅行、会议等作为标签或场景，不作为顶层空间。
- 买断制第一版按单人使用设计，不提供多用户、家庭成员或教学管理。

## 从第一版原型归档的设计边界

第一版 `langotrace-premium-prototype` 的页面本身已无继续参考价值，但其中的设计边界需要保留：

- 不做游戏化闯关风格。
- 不使用大面积 AI 紫蓝渐变。
- 不走传统背单词列表风格。
- 不做普通 SaaS 营销页风格。
- 避免过度卡片化的仪表盘风格。
- 界面主角始终是用户自己的生活记录、照片、情绪、句子、声音和长期语言资产，而不是 AI 聊天窗口或课程关卡。

后续仍值得单独展开的视觉方向：

- 暗色模式。
- 更正式的品牌标识。
- App icon 方向。
