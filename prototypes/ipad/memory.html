设计说明

  • 目标设计：当前实现为 Local Mock；本页固定的是信息结构与文案语气，不代表数据层已经就绪。
  • 不暴露工程概念：界面只使用「沉淀 / 复习 / 掌握」语言，不出现向量索引、embedding 或检索等工程词汇；向量索引是本地可重建派生数据，不进入用户语义。
  • 复习队列的检索与排序方案仍在评估：原型先固定队列入口、数量与「大约 n 分钟」的低压力表达，算法替换不影响此层 UI。
  • 主题分组对应未来标签 / 场景模型：通勤、咖啡、跑步是标签 / 场景，不是语言空间；它们不会被提升为独立空间概念。
  • 沉淀而非建卡：记忆项全部来自生活记录与阅读的显式「加入记忆」动作，来源行保留出处，可回跳原始上下文。
  • 摘要条用文字标签 + 数字共同表达状态，「开始复习」是页面唯一主按钮，保持低压力层级。
