# 外观主题轻量原型

状态：Palette Approved Prototype

创建日期：2026-05-23

审核结论：2026-05-23 用户确认色号审核通过，作为本轮浅色 / 深色实现基准。

## 目的

本目录用于审核 iPhone 设置页和主学习页在浅色 / 深色外观下的视觉方向。

当前文件中的颜色已通过本轮原型审核；正式落地仍以 `docs/plans/active/2026-05-22-feature-appearance-light-dark-foundation.md` 为实现入口。SwiftUI 实现后仍需截图或人工验收，确认真实组件、文字尺寸和状态表达没有偏离原型结论。

## 文件

- `index.html`：浅色 / 深色并排对照原型。
- `styles.css`：候选视觉 token 与页面样式。

## 已审核重点

- 浅色是否保留语迹的温和纸感，但不显得过度米黄。
- 深色是否保持低光环境下的长期可读性，而不是机械反转浅色。
- 设置页选中态是否清楚，并且不只靠颜色表达。
- 主学习页的母语记录、目标语言句子、状态 badge、底部 Tab 是否在两种外观下都清晰。
- 强调色、警告色、本地预览色是否保留各自语义。

## 2026-05-23 专业评估与优化记录

评估方法：

- 使用 UI/UX 可访问性和颜色系统规则检查：普通正文至少 4.5:1，对辅助文字和状态文案也按可读正文处理。
- 检查浅色 / 深色是否共同保持品牌识别，而不是两套互不相关的色盘。
- 检查状态色是否有独立语义，不被强调色或装饰色吞掉。

发现与处理：

- 浅色弱文本原候选 `#6E7B76` 在纸面和面板上的对比度分别约为 3.99:1 和 4.34:1，低于正文可读标准；已调整为 `#5A6963`。
- 浅色警告色原候选 `#B08234` 在 warning soft 背景上约为 2.82:1，不能承载文字或状态标签；已调整为 `#835B1F`，并配合 `#F3E4C9`。
- 浅色背景从更明显的米色 `#F7F3EA` 微调为 `#F6F1E8`，保留纸感但降低奶油色倾向。
- 深色候选的正文、弱文本、强调色、警告色和危险色对比度均达到可读要求，暂不做大幅改动。
- 为按钮和底部 Tab 补充 `focus-visible` 样式，避免原型只考虑触控而忽略键盘焦点。

后续实现仍需验证：

- SwiftUI 实现后仍需 iPhone 截图或人工验收，确认设置页和主学习页在真实控件层级下保持当前可读性。
- 如果平台动态颜色、material 或系统控件导致色值需要小幅等价调整，必须回写外观方案文档并保留对比度证据。
- 原型确认的是浅色 / 深色基础 palette，不代表未来多品牌色、字体或交互样式主题已经完成设计。
