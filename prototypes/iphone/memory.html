设计说明

  • 用户视角不暴露工程概念：页面只有「沉淀 / 复习 / 掌握」三个产品词；向量索引、embedding、检索基础设施等实现细节不出现在任何 UI 文案中。
  • 低压力复习：复习卡用「5 个词句等你回看 · 大约 3 分钟」的邀请式文案，不做连续打卡、欠债计数或红色角标施压。
  • 每条记忆都有来处：「来自 · 记录标题」可点回原记录，复习时回到当初的生活语境——这是与传统背单词 App 的核心差异。
  • 词句 / 整句两类条目：用 pill-neutral 文字标注类型，颜色不是唯一信息；两类在复习中走不同的回看形式。
  • 落地路径：memory candidate 数据已在 GRDB 学习内容主路径中，最近沉淀列表可先做只读展示；复习队列在本地检索方案确定后接入，本页交互结构对两阶段都成立。
