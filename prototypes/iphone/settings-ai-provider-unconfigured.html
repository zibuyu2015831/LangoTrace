配置一个你自己的 AI Provider（如 OpenAI），语迹才能生成学习材料、逐句朗读和解释。密钥只存本机 Keychain，不上传。

语迹本地优先：不内置账号、不收集数据，AI 能力由你自带的 Provider 提供。

设计说明

  • 引导态而非错误态：尚未配置是首次使用的正常起点，采用中性 tone（neutral pill、accent 主操作），不使用红色失败语义；空状态文案是邀请配置，不是报错。
  • 能力为何被 gated：生成学习材料 / 逐句朗读 / 选中解释 / 记忆向量检索都依赖用户自带 Provider 的文本、语音或向量模型；没有 Provider 时这些能力没有可调用的后端，因此统一以「需要 Provider」中性 pill 标注为待解锁，而不是隐藏或佯装可用。
  • 本地优先 + Keychain 隐私边界：语迹不内置账号、不收集数据；添加 Provider 后 API Key 只写入本机 Keychain，非敏感配置进本地 SQLite，二者分离，默认不同步、不上传。
  • 系统级页面：Provider 配置对所有语言空间生效，因此不显示当前语言空间 capsule header；nav-bar 仅保留「设置」返回与「AI Provider」标题。
  • 主操作单一聚焦：引导态只给一个主 CTA「添加 Provider」，进入后即为已配置态的表单页，形成「未配置 → 添加 → 配置 → 测试请求」的连续路径。
