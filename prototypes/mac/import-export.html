导入

从语迹导出包恢复内容到当前空间。

导入前会显示内容预览，不会直接覆盖现有数据。

导出包不包含 API Key、对象存储密钥或任何 Keychain 内容。

设计说明

  • 桌面端是导入导出的自然落点：Mac 拥有完整文件系统语境，备份包导出 / 导入在工作台侧栏拥有一级入口；iPhone / iPad 通过设置内入口复用同一能力。
  • 可恢复备份对应路线项：本页对应路线中「照片 / 音频附件主数据、FTS、导出和可恢复备份」；导出范围里生活记录与学习材料始终包含，附件按体积分级可选。
  • 导入先预览、不直接覆盖：选择导出包后先展示内容预览与合并方式，再由用户确认写入，避免一键覆盖现有空间数据。
  • 密钥边界：导出包不包含 API Key、对象存储密钥或任何 Keychain 内容；备份可以离开本机，凭证永远不随包传播。
  • 当前实现为 unavailable：导入导出尚未实现，本页是目标设计；文件访问权限（security-scoped bookmark）与导出包格式需要独立任务方案定义。
