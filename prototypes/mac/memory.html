设计说明

  • 资料库式高密度浏览是 macOS 专属形态：摘要条 + 四列表格（英文词句 / 中文释义 / 来源记录 / 沉淀日期），行高约 38px，hover 与选中态分别用 surface-2 与 accent-tint 表达。
  • 当前为 Local Mock：记忆主数据、来源回链与复习状态尚未接入真实存储，本页固定的是目标结构，不代表已实现能力。
  • 不暴露向量索引 / Embedding：界面只呈现词句、释义、来源与日期；向量检索是本地可重建派生数据，不出现任何「索引 / 向量」用户概念。
  • 来源回链：Inspector 中的来源记录以链接色呈现，点击回到对应记录详情，保持「记忆来自生活记录」的产品叙事。
  • 复习与检索待独立方案：「开始复习」只是命令位；复习节奏、待复习队列与全文检索的具体行为需要独立任务方案定义。
  • 筛选 chips（全部 / 词句 / 整句 / 已掌握）与 iPhone 记忆 Tab 共享同一套筛选语义，不另造桌面专属状态。
