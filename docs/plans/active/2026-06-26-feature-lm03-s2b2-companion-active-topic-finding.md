## 范围（待实现）

- **方案B 主动找话题**：语伴在「没有用户带入单条记录」时，可主动从用户的生活记录里找话题。
  - **一次性范围授权**：用户显式授权一个范围（时间窗 / 排除标签 / 排除照片原图），不是默认全库可读。
  - **本地 FTS 预筛**：经 `GRDBLocalSearchRepository.search(query:spaceID:perGroupLimit:)`（plan 12 / E9，已就绪）在本机预筛候选条目，**绝不把全库灌进 prompt**。
  - **最小发送**：仅把用户选中 / 系统在授权范围内选出的最小候选条目送进 system prompt（受 S2b-1 的两层隐私 + PII scrubbing 复用约束）。

## 关键设计锚点（实现时展开）

- **范围授权 UI + 持久化**：一次性授权范围（时间窗 / 排除标签 / 排除照片），授权粒度与持久化方式实现时定（倾向会话级或单次操作级，不做长期默认全库授权）。
- **FTS 预筛 → 候选 → 最小发送**：本机 `search(...)` 出候选 → 用户可见可选 → 仅选中条目入 prompt；预览如实披露「将发送：选中的 N 条记录」。
- **与方案A 区分**：方案A（S1）= 用户显式带入单条记录；方案B（本片）= 语伴在授权范围内主动找。两者都经隐私闸。
- **复用 S2b-1**：注入预览投影、PII scrubbing、per-conversation 开关直接复用，不另造。
